## How to use this register

- Every task has an immutable `EM-###.##` ID, **one tangible deliverable** and a **pass condition** after `→`. Check it only with exact artifact SHA, dated proof, test/output and reviewer scope. Work can be part-complete while a milestone remains open.
- Proposed subtask boxes start **unchecked / not independently re-audited**. This is *not* a statement that the underlying engineering work is absent. Previously accepted canonical milestones remain accepted; do not silently reopen or re-award them merely because this decomposition adds tracking granularity. Link pre-existing receipts before transferring subtask evidence.
- Use `DONE` only on proof; `IN_PROGRESS` with actual measured evidence; `BLOCKED` with exact missing dependency; `FAILED` when a negative/quality test fails; `NOT_AUDITED` for unknown. A source revision, WAV/MP4 hash change or reviewer-model change invalidates dependent approvals.
- If a parent is open, **subtask percentage = independently accepted child proofs / frozen child count**. This is progress *inside that parent only*, never new canonical 46 credit or a subjective quality score. For a checked parent, audit status separately instead of displaying misleading zero percent. Keep original `26/46` until canonical source changes with earned evidence.
- This is **not** approval to execute hundreds of independent PRs. Bundle coherent dependent steps under the existing admitted owner and one reviewable PR; obey `AGENTS.md`, `CURRENT_SPRINT.md`, WIP 3, source-bound science, independent calibration, exact-head full CI, sole protected merge controller, and separate publisher authorization.
- **Numbering conflict:** canonical `EM-027` below is the already checked PubChem source-reading hold. PR [#6817](https://github.com/Razzleberrytt/hippie-scientist-site/pull/6817) informally calls an unfinished *muted-viewer* research gate “#27” at a 99% machine-proxy score. That open work belongs to canonical **EM-034** (and semantic/independent review EM-017/036), not EM-027. Do not transfer 99% or completion credit across IDs. PR #6817 is a candidate, not merged canonical approval.
- **Release proof is not a mechanical QA score:** first excellent first-render **0/1**, five consecutive excellent varied first renders **0/5** at source audit; keep quality, independent scientific review, real handset and publication gates distinct.

# EvidenceMotion Lane 1 — Nano Agent Execution Instructions

> **RESEARCH-ONLY NON-SCORING INSTRUCTION LAYER.** Each existing atomic card receives three smaller agent-execution instructions. Every checkbox is a *proposed instruction*, not a new verification status, PR, WIP slot or earned card. Consult canonical `COMPLETION-CHECKLIST.md`, 243-subtask register, original `atomic/01-operating-science.md` and exact receipts before operating.

## Agent safety and handoff protocol

Read `AGENTS.md` and current sprint; select only one authorized existing ticket/PR. Keep `mayPublish=false`. Preserve locked narration/science, no daily video work, no fabricated reviewer/device acceptance, and owner-controlled serial merge. Treat UNKNOWN as HOLD. These nano IDs inherit their atomic parent; do not add them to 1,590, 243, 46, or progress counts.

**Per item:** use a real unit key `@unit-ID` only after inventory; all three nano steps share that unit. A checkmark here records agent notes, not source-backed completion; real proof goes to the existing atomic ledger after independent reconciliation.

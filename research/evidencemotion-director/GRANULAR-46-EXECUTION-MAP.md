1. **These are work units, not newly accepted facts.** Every subtask begins unchecked / **NOT_SUBTASK_AUDITED** until its own immutable evidence is linked. A canonical checked parent means the *parent acceptance* was previously recorded; do not decrement it merely because the finer ledger is new. Do not mechanically promote all children as accepted based only on the parent checkbox.
2. Each ID is permanently bound to the original canonical file's **sequential numbered checkbox**, not to PR nicknames or conversational numbering. **EM-027 is the already-complete PubChem source-card hold, NOT the much larger current muted-comprehension QA effort sometimes called "#27" in PR #6817.** The latter crosses EM-017, EM-028, EM-034 and EM-036; cite the actual relevant IDs, not the informal nickname.
3. Every check requires a **direct artifact + a recorded pass test**; proposed proof in the right-hand clause is *not evidence that the test ran*. Each subtask receipt should store state (NOT_AUDITED/IN_PROGRESS/BLOCKED/FAILED/ACCEPTED), timestamp, owner issue/PR, source/audio/film hash, run ID, evidence link, and blocker. Scope not relevant? Mark N/A with a reason; never invent a success percentage.
4. Count **accepted subtasks / defined subtasks** for a given parent once audited. The canonical 46 is changed **only after all original parent acceptance conditions** are truly met. Historical engineering, research, story-quality and real-world publication gates are separate. Machine scores such as "99%" are scoped proxies, not 99% of an accepted final film.
5. No task here admits new WIP, sidesteps [CURRENT_SPRINT](../../docs/CURRENT_SPRINT.md), grants science/clinical approval, manufactures a qualified reviewer, authorizes publication, or merges to protected main. Owner issue [#6743](https://github.com/Razzleberrytt/hippie-scientist-site/issues/6743) and [PR #6817](https://github.com/Razzleberrytt/hippie-scientist-site/pull/6817) remain independent of this documentation-only plan.

# Social presentation v2 notes

This upgrade targets the parts of automated social publishing that can make an evidence-correct post still look low-quality in the feed.

## Changes

- Carousel assets use a stronger editorial hierarchy, branded lockup, evidence-role labels, restrained scientific motifs, and a hook-only swipe cue.
- Campaign attribution still uses the governed tagged destination, while Metricool is instructed to shorten HTTPS links at publication so readers are not shown the full UTM query string.
- Creative spec v13 is the expected accessibility-contract version.

## Non-negotiable boundaries

- Scientific findings and limitations remain governed upstream.
- Presentation code may wrap and lay out factual text but may not rewrite it.
- The canonical evidence destination remains unchanged.
- Attribution parameters remain in the destination even when the visible published link is shortened.
- Source and disclosure remain present in rendered assets.

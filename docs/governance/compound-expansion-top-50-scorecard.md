# Compound Expansion — Top-50 Opportunity Scorecard

**Created:** 2026-09-22  
**Purpose:** Seed the governed medication/psychoactive expansion queue with a transparent prioritization model. This is a planning artifact, not scientific or regulatory evidence.

## Scoring model

Each entity receives a 1–5 editorial planning score for:
- **Connection** — strength of connection to existing THS authority/routes.
- **Evidence depth** — expected depth of authoritative/human evidence available for a rigorous profile.
- **Public/safety value** — value of clear evidence/safety context.
- **Search/AI opportunity** — initial editorial opportunity estimate; replace with measured query/search data when available.
- **Governance risk** — 1 low → 5 high. Higher risk raises review requirements rather than publication priority.

**Priority band** is deliberately qualitative until measured search data are joined. No traffic numbers are invented.

## Existing-authority signals discovered before scoring

Repository discovery already shows dedicated or substantial existing material for caffeine, nicotine, dextroamphetamine/narcolepsy, zolpidem/sleep safety, SSRI comparison/interactions, and restricted-term handling for ketamine/psilocybin. Those connections raise their integration value but do not prove search demand.

## Execution rule

1. Start with A-band entities that can reuse existing authority and have manageable governance risk.
2. High-risk A-review entities require the stricter medication/psychoactive provenance contract before publication.
3. Join measured GSC/AI-query data when available and replace the estimated Search/AI column.
4. Create small entity- or cluster-scoped implementation issues/PRs; never bulk-publish the table.
5. Re-score after the first 10 entities have measurable impressions/citations.

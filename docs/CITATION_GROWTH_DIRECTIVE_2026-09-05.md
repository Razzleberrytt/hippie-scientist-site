**Status:** User-directed swarm priority amendment
**Applies to:** Discovery/SEO prioritization and citation-oriented Authority/Content support
**Tracking issue:** #5338

## Objective

Shift the swarm from generic enrichment/output maximization toward **measured AI citation-share growth** using fresh Bing AI Search Queries / grounding reports as a first-class feedback signal.

The optimization target is not “publish more pages.” It is to raise the underlying citation floor, grow rolling citation share, expand cited-page breadth, reduce the size/frequency of negative daily moves, and recover faster when normal Bing volatility produces a down day.

A zero-negative-day guarantee is not technically possible because Bing controls query demand, sampling, citation selection, crawl timing, ranking systems, and reporting behavior. The swarm must therefore optimize the controllable leading indicators and rolling outcomes rather than treat every single-day decline as failure.

## Swarm execution policy

When legal under WIP, evidence, provenance, safety, accessibility, and release gates, Discovery/SEO should use each fresh report to produce a ranked queue based on **expected citation upside**, not raw article count.

Each execution cycle should prefer:

1. **2–3 winner upgrades** — strengthen existing pages supporting high-volume/high-headroom queries.
2. **3–5 adjacent intent gaps** — fill missing query coverage immediately around those winners only when the intent is genuinely distinct and non-duplicative.
3. **Internal-link reinforcement** — route relevant authority into the selected target set.
4. **Answer extraction quality** — improve concise direct answers, section structure, comparison clarity, schema, factual freshness, and machine-readable identity.
5. **Evidence + safety completeness** — strengthen citations, uncertainty boundaries, contraindication/safety context, and provenance without overclaiming.
6. **Measurement loop** — preserve the prior report snapshot, compare share/citations/cited-page movement, and re-rank the next cycle.

## Ranking contract

For each query, record when available:

- current citations;
- current citation share;
- implied citation pool / estimated remaining headroom;
- topical cluster;
- defend / expand classification;
- mapped canonical target URL(s);
- last verified report date;
- recommended next action;
- evidence/safety dependencies;
- post-change observation window and outcome.

Query-only exports **must not invent target URLs**. When page-level attribution is unavailable, target ownership remains `Unknown` until resolved from valid telemetry or deterministic site/query mapping.

## Success metrics

Primary:
- rolling citation share on target sleep clusters;
- rolling cited-page floor;
- total citations across aligned rolling windows.

Secondary:
- percentage of targeted queries gaining share;
- number of cited pages contributing to the cluster;
- magnitude and frequency of negative daily moves;
- recovery time after declines;
- citation gain per unit of implementation effort when comparable effort observations exist.

Do not infer causation from one report or one-day movement. Scale only after repeated attributable improvement or a strong enough deterministic content-quality rationale under existing governance.

# The Hippie Scientist — granular proof tasks for all 16 systems

**Proposal on 2026-10-15.** Source authority: [THS system completion program](../THS_SYSTEM_COMPLETION_PROGRAM_V1.md) and its four domain files, not this microtask map. Original 16 families × 8 outcomes = **128 parent goals**. This file defines **512 new smaller work items** (four bounded proofs per parent), but none is accepted merely by authoring this document. The accepted documentation crosswalk MD-01-01 stays accepted, the other parent goals retain their prior NOT_AUDITED/BLOCKED status; no new system completion percentage is asserted.

## Rules and evidence accounting

- **First pin identity, then produce one visible case, deliberately break it, then validate real-world acceptance.** Each row describes a concrete deliverable. A green fixture proves only the tested fixture; actual client, science, social posting, paid receipt or real user outcomes still need actual authorized evidence.
- A subtask starts **NOT_AUDITED** even if its parent was previously checked; previously reviewed parent evidence is preserved. Backfill individual subtask passes only after checking dated source/run receipts. **Each unique ID is permanent**; subtask count is not additive to the 46 EvidenceMotion, 150 reconstructed P0, or 128 original program outcomes.
- For every status change record `owner ticket/PR · exact source/head/media SHA · date · test or field receipt URL · positive/negative verdict · next action · blocker`. Track `ACCEPTED/defined subtasks` **for each parent only**, and don't turn partially green tests into a completed parent or arbitrarily increase percentages.
- This does **not** create 512 sprint tickets, new schedulers, a fourth D/R/A lane, new source stores, owner permissions or clinical/media release rights. All code must follow [AGENTS](../../AGENTS.md), [CURRENT_SPRINT](../CURRENT_SPRINT.md), required exact-head checks and the sole protected merge controller.
- The detailed 258-item video map is [EvidenceMotion granular 46](../../research/evidencemotion-director/GRANULAR-46-EXECUTION-MAP.md). These MD-01 subtasks are higher-level outcome proof **crosswalks**, not duplicate credit.

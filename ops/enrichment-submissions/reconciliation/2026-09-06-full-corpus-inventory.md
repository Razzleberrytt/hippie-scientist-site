# Full Enrichment Corpus Inventory — 2026-09-06

## Purpose

Durable capture of the scientific-enrichment corpus researched in the current enrichment program. This is a reconciliation/index artifact, **not a canonical evidence mutation**. It exists so researched findings, nulls, safety signals, identity firewalls, retractions, and unresolved extraction work are not lost while governed promotion proceeds separately.

## Governance rules

- Human clinical evidence is authoritative for clinical claims; observational, mechanistic, animal, and traditional evidence remain distinct.
- Exact intervention identity is required: species, plant part, extract/preparation, dose, route, formulation, strain, isolated constituent, and combination status are preserved where known.
- Null, mixed, heterogeneous, and low-certainty results are first-class findings.
- Biomarkers/surrogates do not become disease prevention, treatment, or performance claims.
- Reviews/meta-analyses retain review-level evidence class and do not become primary RCT records.
- Retracted, withdrawn, superseded, or otherwise ineligible sources are quarantined rather than promoted.
- This inventory does not edit the workbook, canonical profiles, generated runtime evidence, or publication eligibility.

## G. System defects / control-plane work captured with the corpus

1. **Source identity resolver:** common-token overlap must not establish intervention identity. Required examples: botanical sage vs SAGE-718/Sage Therapeutics; taurine vs citrulline-malate PMID 20386132.
2. **Evidence-class authority:** source metadata must constrain submission `evidenceClass`; a submission cannot promote a review/meta-analysis to human-clinical primary evidence.
3. **Source eligibility:** `active:true` alone is insufficient; withdrawn/superseded/archived sources must fail closed; preprints need explicit lower-status handling.
4. **Formulation firewall:** product-specific, extract-specific, route-specific, strain-specific, and combination evidence must not inherit to generic entities.
5. **Negative/null preservation:** null coprimary endpoints and discordant secondary endpoints must survive reconciliation.
6. **Retraction quarantine:** PMID 42527229 / retracted aged-garlic meta-analysis PMID 39437887 must remain absent from canonical source registry/ledger/derived evidence.

## Current disposition model

| Bucket | Meaning | Action |
|---|---|---|
| New + source-valid | Exact source and identity verified | Stage for governed review/promotion |
| Already canonical | Existing canonical evidence | Reconcile/propagate only; no duplicate |
| Source not admitted | Missing/inactive/unverified source | Keep staged/blocked |
| Duplicate fingerprint | Same evidence already staged/canonical | Record dedup; do not duplicate |
| Preclinical only | No human clinical basis | Preserve preclinical class |
| Safety-only | Safety signal without efficacy | Keep safety-specific |
| Null/mixed | Outcome does not support simple positive claim | Preserve exact null/mixed result |
| Retracted/invalid | Source cannot support evidence | Quarantine/fail closed |
| Needs extraction | Source identified but exact details incomplete | Research queue; no premature claim |
